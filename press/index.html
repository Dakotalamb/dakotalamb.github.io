Standard boilerplate

Forged Destiny Gaming is an independent game collective and creator organization founded in Kentucky in 2026. FDG supports original games, independent creators, and collaborative projects through shared infrastructure, community, promotion, and creator-first tools while protecting each member's ownership and individual voice. Its projects include the multiplayer survival-horror game No Exit Necessary and Forge Creator Hub, a scheduling and collaboration platform built by creators for creators.

Projects

What we are building

Creator technology

Forge Creator Hub

A creator-first scheduling, private-team, and collaboration platform designed to replace scattered graphics, messages, and planning tools with one schedule that updates everywhere.

  • Public and unlisted creator schedules
  • Private teams, chat, polls, and event planning
  • Collaboration listings, applications, RSVPs, and reminders
  • Calendar feeds, QR sharing, embeds, and Twitch tools
  • Free core tools with optional Supporter personalization

Game in development

No Exit Necessary

A multiplayer Backrooms-inspired survival-horror game where escaping is not the objective. Players explore an impossible liminal world, gather resources, craft, build a functional base, and learn how to thrive alongside dangerous anomalies.

  • Planned multiplayer for 1–6 players
  • Exploration, crafting, and base building
  • Expandable environments and continued development
  • Original creatures alongside recognizable liminal-horror influences
  • Developed under Forged Destiny Gaming
